# tarea3-crud-git-flow
Desarrollo de un sistema CRUD funcional aplicando Git Flow, ramas feature, hotfix y Pull Requests para la asignatura Programación III.
 
## Operaciones CRUD y flujo 
- Crear, Listar, Actualizar y Eliminar productos en InventarioFerreteria. 
- Flujo de ramas: feature/* - - -
- Pruebas y validacion en qa antes de pasar a main.
